# COM-VA OS3

COM-VA OS3 è un'applicazione web per la gestione degli appuntamenti e delle presenze del personale di un ufficio. Si usa in rete interna e non è un servizio pubblico.

## Integrazione con Google Calendar

L'applicazione può collegarsi, su richiesta esplicita dell'utente, al suo Google Calendar per mantenere allineati gli appuntamenti registrati nell'applicazione e quelli presenti sul calendario.

- Informativa sulla privacy: [PRIVACY.md](PRIVACY.md)
- Contatti: va.vvfaaa@gmail.com

## Termini di utilizzo

L'applicazione è fornita per uso interno, senza garanzie di disponibilità continua. L'utente può scollegare Google Calendar in qualsiasi momento (vedi l'informativa sulla privacy).
